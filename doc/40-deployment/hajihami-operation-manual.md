# 哈基哈米运维手册

更新时间：2026-05-27

本文档面向系统管理员，介绍哈基哈米社区的日常运维、问题排查及配置管理。

## 1. 核心服务监控

### 1.1 服务状态检查
使用 Spring Boot Admin (端口 9100) 或 Nacos 控制台实时监控各微服务节点的健康状况。

### 1.2 日志审计
- **操作日志**：在“系统管理 > 操作日志”中查看管理员的后台操作记录。
- **Webhook 日志**：在“开放平台 > Webhook 管理 > 调用日志”中监控异步推送的成功率及错误原因。

## 2. 故障排查 (Troubleshooting)

| 现象 | 可能原因 | 排查步骤 |
| --- | --- | --- |
| 开放 API 返回 401 | API Key 不正确或已停用 | 1. 核对请求头 `X-Hakimi-Api-Key`; 2. 在后台检查 Key 状态 |
| Webhook 推送持续失败 | 推送目标地址不可达或超时 | 1. 检查调用日志状态码; 2. 使用“分发测试”功能手动触发 |
| 前台 SSR 渲染报错 | 后端网关连接超时 | 检查 Nuxt 服务器与后端网关的内网连通性 |
| 统计数据未更新 | Redis 缓存未及时刷盘 | 检查 `hjm-music-web` 的定时任务日志 |

## 3. 配置维护

### 3.1 开发者配置
- **API Key**：通过“开放平台 > API Key 管理”进行增删改。
- **Webhook**：通过“开放平台 > Webhook 管理”配置订阅事件及目标 URL。

### 3.2 运营参数
在“前台运营配置”中维护以下关键参数：
- `hajihami.operation.announcements`: 首页公告
- `hajihami.operation.recommend_cards`: 推荐位
- `hajihami.incentive.activity`: 活动配置

## 4. 备份与恢复
- **数据库**：使用 `pg_dump` 每天备份 `postgres` 数据库。
- **配置文件**：Nacos 配置建议导出为 ZIP 文件定期备份。
