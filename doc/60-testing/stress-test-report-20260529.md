- **虚拟线程表现**：在 100 并发下，`hjm-music-web` 的 CPU 占用保持在 40% 以下，内存增长平稳，未出现 OOM 或线程池耗尽。

## 4. 结论

当前 S6 开放 API 性能已达到上线门槛要求，单机环境可支持 100 并发下的稳定访问。
